# Security Policy

## Reporting a vulnerability

**Do not report security problems in public issues, discussions, or pull
requests.**

Use GitHub private vulnerability reporting:

1. Open the affected repository.
2. Go to the **Security** tab.
3. Select **Report a vulnerability**.
4. Describe the problem, the affected version, and steps to reproduce.

Only the maintainer can see the report. You can discuss it and follow the
fix privately in the advisory.

## What to expect

- Acknowledgement within 7 days.
- An assessment and, if confirmed, a plan for a fix.
- Credit in the advisory when the fix is released, unless you prefer to stay
  anonymous.

## Supported versions

Only the latest release of each project gets security fixes, unless the
project's own `SECURITY.md` says otherwise.
