# Getting Help

## Questions and ideas

Ask in [Discussions](https://github.com/AnotherMike-exe/.github/discussions)
— or in the project's own **Discussions** tab if it has one. Discussions keep
issues free for confirmed bugs and planned work, and answers stay searchable
for the next person.

Include:

- The project and version
- How you run it (Docker, Unraid, bare metal, ESPHome, hardware revision)
- What you tried and what happened

## Bugs

If you are sure something is broken, open an issue with the **Bug report**
form in the affected repository.

## Security

See [SECURITY.md](SECURITY.md). Never post vulnerabilities publicly.

## Response times

These projects are maintained in spare time. There is no guaranteed
response time.
